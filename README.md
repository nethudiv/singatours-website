# SingaTours – Completed HTML Portfolio Project

A responsive multi-page Singapore travel website built with HTML, CSS, Bootstrap and JavaScript.

## Added
- Linked home destination and experience cards
- Six destination detail pages
- Four experience detail pages
- Three package detail pages
- Gallery category filters: All, City, Nature, Luxury, Food, Nightlife
- Full-screen image lightbox with previous/next navigation and keyboard controls
- Linked package buttons and footer popular tours
- Shared detail-page layout and responsive styling

## Open
Start with `index.html`. The site works as a static HTML project and does not require PHP/XAMPP.
